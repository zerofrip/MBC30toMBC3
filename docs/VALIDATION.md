# 検証条件と再現方法

## 確認日・対象

2026-11-15、未改造日本語版から生成したREADME記載ハッシュのMBC3版をローカルで検証。ROMやセーブを外部へ送信していません。

移設後のビルドではRGBDS 0.3.4、`lazy_ips` コミット `2a4918b4b0a4ad9bb139c2907c00decfa0cf9188`、`gb-asm-tools` コミット `5ff0fead255a093d33baddb46c77a4943bb929d7` を使用しました。153バイトIPSと適用後ROMのSHA-256はREADMEの値に一致し、`lazy_ips`での再適用も一致しました。ファイル保護テスト3件、CPUテスト、画面操作4ケース、Ghidra監査を移設後のコードで再実行しています。

CPU・画面操作テストはPyBoyのSM83 CPUと標準MBC3を使用しました。ローカルのPyBoy環境には日本語原版用のMBC30対応変更も含まれますが、このパッチ適用後ROMのヘッダは32KB SRAMであり、標準MBC3側を使用します。同一環境そのものやプライベートなテストデータはリポジトリに含みません。他バージョンのPyBoyとの互換性は未確認です。

## CPUテスト

`tools/verify_cpu.py` は入力ROMの既知ハッシュを確認し、以下をエミュレーションします。

- 全256選択値×フラグ2状態の512ケース。AF・BC・DE・HL・スタックを保持。
- 無効なSRAM選択時の8KB書き込みを遮断し、32KB全体が不変であることを確認。
- ROMバンク1～127から呼び出し、元のROMバンクへ復帰。
- RTCレジスタ8～12の読み書き。
- 男女の追加データ保存・ロード、保存先が予約した9バイト以内であること。
- モバイル状態、配布フラグ、モバイル交換状態が0。
- 新規セーブ初期化後にも追加データが保持されること。

結果は出力先の `cpu_results.json` に記録されます。

## 画面操作テストのfixture

64KBの未改造日本語版テスト用セーブが必要です。実行時にコピーをメモリ上で32KB化します。これはテスト専用処理であり、任意の既存セーブを安全に移行するための機能ではありません。

想定するfixture：主人公の自室（マップグループ24／番号7、座標y=3・x=3）、手持ち1匹、図鑑・ポケギア未取得、モバイル未設定、GSボール未受領。メニューの4番目がレポートであること。fixtureは配布しません。

テストは男女それぞれについて、自宅とコガネPCCで歩行・レポート保存・32KBバッテリーセーブからの再起動を実行します。位置、性別、主人公情報、手持ち、ボックス領域を確認します。出力先に `play_results.json`、テスト用セーブ、画像、エミュレータステートを生成します。これらは公開しないでください。

PCCへの移動はテスト時だけROMバンク25の空き領域へ短い移動スクリプトをメモリ上で差し込み、コガネの屋外に移動してから実際の入口を歩いて入ります。この移動コードは生成IPSに含みません。

## Ghidra

解析環境：Ghidra 11.4.2、Java 21、GhidraBoyのSM83ローダー。各ツールは別途用意してください。以下はリポジトリ直下で実行する例です。

```sh
mkdir -p build/ghidra-project
/path/to/ghidra/support/analyzeHeadless build/ghidra-project MBC3Audit \
  -import build/candidate.gbc -noanalysis \
  -scriptPath tools/ghidra \
  -postScript CrystalMbc3Audit.java build/ghidra_patched.txt \
  -deleteProject > build/ghidra.log 2>&1
```

JavaスクリプトはROM0のSRAM制御と追加処理、バンク5の保存・ロード、バンク65・92のモバイル判定を命令単位で出力します。Ghidraログに `MBC3 audit disassembly saved locally` があること、出力命令が `src/patch.asm` と対応していることを確認します。解析結果の逆アセンブルもローカル限定です。

## 検証の限界

ハッシュ一致は生成物の再現を示しますが、全イベントの正しさを証明するものではありません。EverDrive GB X7の実機、実機での保存・電源断、長時間の時計経過、全ストーリー、ケーブル通信、ステートセーブは未検証です。
